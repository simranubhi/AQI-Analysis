# Air Quality Index (AQI) Analysis Dashboard

## Overview
An AQI analysis dashboard built using R to explore air-quality data, analyze pollution patterns, and visualize trends through an interactive dashboard.

## Features
- Visualization of air-quality indicators
- Exploration of pollution patterns and trends
- Data cleaning and exploratory data analysis (EDA)
- Graphical presentation of air-quality insights

## Technologies Used
- R
- Data Analysis
- Exploratory Data Analysis (EDA)
- Data Visualization

## Project Structure
- `app.R` — Dashboard application
- `scripts/data_preprocessing.R` — Data preprocessing
- `data/processed/` — Processed dataset
- `data/raw/` — Raw datasets (some large files are excluded from GitHub)

## How to Run
1. Install R and RStudio.
2. Install the packages required by the project.
3. Open `AQI_Dashboard.Rproj` in RStudio.
4. Run the dashboard using the appropriate command for your application.

## Note
The large raw datasets `city_hour.csv` and `station_hour.csv` are not included in this repository. Add them to `data/raw/` locally if your application requires them.
